Methods & limitations

Saved model results

This GitHub Pages edition displays the original saved validation predictions. Selecting a video and model retrieves an existing result; it does not execute a neural network. Predictions are available here for 20 frozen validation videos and two GNN conditions. The original local demo retains real model inference.

The similarity GNN was selected by validation MAE. The structural GNN is an alternative condition. Values are copied from the frozen prediction file; no training, fitting, calibration or new evaluation was performed to build this edition.

Graph interpretation

The explorer loads one structural subgraph at a time. The three relations are video_has_aspect, video_has_evidence and aspect_supported_by_evidence. The original model used structural edges in both directions. Type and neighborhood filters change only the drawing. Supplied relations are not established ground truth or causal explanations.

In the original similarity condition, training links were bidirectional between training videos, with validation-to-training links added for inference. Under that implementation, validation roots received no training-neighbor messages through those similarity links. Neighbors were selected from the full cohort, so the extension was not strictly inductive.

Historical observations and missing values

Titles and historical observed views come from the supplied cleaned metadata. Observed views were separate from model features. Capture times differ and some are unavailable; these are historical cumulative snapshots, not current counts or fixed-horizon forecasts. Blank applicable fields appear as “Unavailable”; fields for another node type appear as “Not applicable”.

Evaluation scope

Training: 174 videos; validation: 20; test: 21. MAE and RMSE are measured on ln(1 + views), not raw view counts. Spearman measures ranking association. Campaign grouping used recorded labels and did not guarantee semantic campaign isolation. Small sample sizes and the similarity implementation limit generalization claims.

This public edition includes display data and aggregate evaluation metrics. It does not include model checkpoints, preprocessing objects, conversation transcripts, or arbitrary-video prediction. The full local research demos remain separate.
